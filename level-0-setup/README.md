## 1. VS Code einrichten
Öffne diesen Ordner in VS Code.

## 2. Die "Live Server" Erweiterung
Damit du deine Änderungen sofort im Browser siehst, ohne die Seite jedes Mal neu laden zu müssen:
1.  Klicke links in VS Code auf das Icon mit den Quadraten (**Extensions**).
2.  Suche nach `Live Server`.
3.  Klicke auf **Install**.

## 3. Browser-Konsole öffnen
Wir werden viel mit der Konsole arbeiten. So öffnest du sie in deinem Browser (Chrome oder Firefox):
*   Drücke `F12` oder `Strg + Umschalt + I`.
*   Klicke auf den Reiter **Konsole** (oder **Console**).

Hier siehst du später Fehlermeldungen und Ausgaben deines Programms.
