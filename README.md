# 🚀 Code-Abenteuer: Dein Tag als Software-Entwickler

Hallo! Schön, dass du heute da bist. Heute wirst du nicht nur zuschauen, sondern selbst zum Architekten deiner eigenen Programme werden.

In diesem Repository findest du alles, was du für deinen Praktikumstag brauchst. Wir fangen ganz einfach an und am Ende des Tages hast du deine eigenen Spiele programmiert!

## 🛠 Was wir heute nutzen
*   **VS Code:** Dein Werkzeug, um Code zu schreiben.
*   **Browser (Chrome oder Firefox):** Hier schauen wir uns an, was dein Code macht.
*   **HTML:** Das Gerüst deiner Webseite (wie die Wände eines Hauses).
*   **CSS:** Das Aussehen (wie die Farbe der Tapete).
*   **JavaScript:** Die Logik (wie die Lichtschalter und die Elektrik).

## 💡 Drei goldene Regeln für heute

1.  **Fehler sind super!** Jeder Fehler, den du machst, bringt dir bei, wie Code funktioniert. Wenn es nicht klappt: Lies die Fehlermeldung, probier etwas Neues oder frag deinen Mentor.
2.  **Verstehen statt Kopieren!** Tippe den Code selbst ab, anstatt ihn zu kopieren. Nur so lernen deine Finger und dein Kopf, wie es geht.
3.  **Frag "Warum?"** Wenn etwas funktioniert, frag dich kurz: Warum klappt das eigentlich gerade?
